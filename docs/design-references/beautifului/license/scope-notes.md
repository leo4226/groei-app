## What this library contains

This folder contains Floreren-authored summaries and metadata. It does not contain a copy of Beautiful UI source code or assets.

## What the upstream MIT licence means here

The MIT licence can allow reuse of covered software and documentation if its notice is retained. It does not make every item visible on the website reusable without review.

**Floreren decision:** treat branding, logos, marketing copy, fonts, compiled assets, screenshots, and example data as reference-only or out of scope unless a future issue separately verifies rights and records approval.

## If a future task proposes code reuse

1. Confirm that the exact source and version are covered by the current licence.
2. Keep the required copyright and permission notice with substantial copied portions.
3. Check dependencies, custom tokens, global CSS, security, accessibility, and Floreren compatibility.
4. Obtain an issue that explicitly asks for reuse. Record the decision in the PR.

This is implementation guidance, not legal advice.
