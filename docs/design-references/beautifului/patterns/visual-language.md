# Visual language observations

These are attributed observations, not Floreren requirements or copied tokens.

## Foundation

- **Observed upstream:** the catalogue uses a quiet neutral base with restrained semantic colour.
- **Observed upstream:** blue carries primary/action emphasis; green signals positive or complete; red signals negative or deleted; orange appears for warning or a secondary data series.
- **Observed upstream:** dense controls sit inside spacious demonstration areas, with hairline borders and restrained shadows.
- **Observed upstream:** cards, controls, and chips use a small-radius hierarchy rather than one universal shape.
- **Observed upstream:** interface text is Inter-like; technical values use a monospace treatment.

## How to interpret it for Floreren

- **Inferred:** semantic colour is most useful when paired with an explicit state label or icon, especially for care status and destructive changes.
- **Inferred:** a calm surrounding layout can make a compact care row, map control, or confirmation surface easier to scan without making the control itself large.
- **Floreren decision:** preserve Floreren's existing palette and component conventions. Do not introduce `Beautiful UI` tokens or copy visual measurements from a screenshot.
- **Not verified:** exact colour values, spacing scale, typeface, contrast ratios, and responsive breakpoints were not measured.
