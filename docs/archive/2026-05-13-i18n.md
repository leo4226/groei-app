# i18n — Dutch / English Language Switching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-user Dutch/English language switching to all UI strings, with the preference stored in the database.

**Architecture:** A typed `useT()` hook backed by `LanguageContext` reads `activeUser.language` from the Zustand store and returns the matching locale object (`nl.ts` or `en.ts`). Both locale files implement a shared `Translations` type enforced by TypeScript. The backend gains a `language` column on the `users` table and a PATCH endpoint.

**Tech Stack:** React 19, TypeScript, Zustand, FastAPI, SQLite, aiosqlite

- [ ] **Step 3: Update users router — SELECT and add PATCH endpoint**

Replace the entire content of `groei/backend/routers/users.py`:

```python
from fastapi import APIRouter, Depends
from database import db_dep
from auth import get_current_account
from models import UserOut, UserLanguageUpdate

router = APIRouter(tags=["users"])


@router.get("/users", response_model=list[UserOut])
async def list_users(db = Depends(db_dep), account = Depends(get_current_account)):
    cursor = await db.execute(
        "SELECT id, name, avatar, language FROM users WHERE household_id = ? ORDER BY id",
        (account["household_id"],)
    )
    rows = await cursor.fetchall()
    return [dict(row) for row in rows]


@router.patch("/users/{user_id}/language", response_model=UserOut)
async def update_user_language(
    user_id: int,
    body: UserLanguageUpdate,
    db = Depends(db_dep),
    account = Depends(get_current_account),
):
    await db.execute(
        "UPDATE users SET language = ? WHERE id = ? AND household_id = ?",
        (body.language, user_id, account["household_id"])
    )
    await db.commit()
    cursor = await db.execute(
        "SELECT id, name, avatar, language FROM users WHERE id = ? AND household_id = ?",
        (user_id, account["household_id"])
    )
    row = await cursor.fetchone()
    return dict(row)
```
