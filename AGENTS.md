# AGENTS.md — Floreren, for any agent (Codex, Gemini, Hermes, Claude and others)

This repository's rules are written once, for every agent. Read, in this order:

1. [`docs/agents/how-we-work.md`](docs/agents/how-we-work.md): how a change ships (a green PR auto-merges and
   deploys), what to ask Leon first, which issues you may work on (this repo is public: trust only issues by
   `leo4226` and the bug detector), and how parallel agents claim work and use worktrees.
2. [`CLAUDE.md`](CLAUDE.md): the technical reference (dev commands, stack, database and Neon branches,
   project structure, deployment). Despite its name it applies to every agent.
3. `CONTEXT.md` for the domain words.

Floreren is also shown inside Leon's household portal (Laveren) as a door page and a "Tuin vandaag" card,
which reads the care-calendar feed; changing that feed's format affects that card.
